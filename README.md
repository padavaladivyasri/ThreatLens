# 🛡️ ThreatLens – Intelligent Security Log Analyzer

## 📌 Project Overview

ThreatLens is a cybersecurity web application developed using Python and Flask. It analyzes server log files to detect suspicious activities such as failed login attempts, unauthorized admin access, HTTP errors, and suspicious IP addresses. The application generates a security report with charts and a downloadable PDF.

---

## 🚀 Features

- User Login Authentication
- Upload Security Log Files
- Detect Failed Login Attempts
- Detect Admin Access Attempts
- Detect HTTP 404 Errors
- Detect HTTP 500 Errors
- Detect Suspicious IP Addresses
- Threat Level Classification (Low, Medium, High)
- Security Events Bar Chart
- Downloadable PDF Report
- Professional Dashboard UI

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/padavaladivyasri/ThreatLens.git
```

2. Open the project folder

```bash
cd ThreatLens
```

3. Install the required libraries

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python3 app.py
```

5. Open the application in your browser.
